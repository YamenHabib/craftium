# Spider Attack Easy

A more challenging variant of the original SpidersAttack environment.

## Differences from Original

| Setting | Original | This Variant |
|---------|----------|--------------|
| Walk velocity | 1 | **2** |
| Run velocity | 3 | **7** |
| Spider spawn Z | -10 | **-5** (closer) |
| Spider HP | 25 | **1** (one-hit kill) |
| Player HP | 20 | **1** (one-hit death) |

## Wave System

Same as original: 1 → 2 → 3 → 4 → 5 spiders per wave.

## Rewards

- Kill spider: **+1**
- Player dies: **-1**
- Otherwise: **0**
